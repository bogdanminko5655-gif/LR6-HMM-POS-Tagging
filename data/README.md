# Дані

`WSJ_02-21.pos` (навчання) та `WSJ_24.pos` (тест) завантажуються автоматично при запуску `lab6.py` або `LR6_Colab.ipynb` з освітнього GitHub-репозиторію. Файли не входять до архіву через розмір та права на корпус.

Якщо автоматичне завантаження не працює, помістіть обидва `.pos` файли до цієї папки вручну. Формат: один рядок `WORD<TAB>TAG`, порожній рядок між реченнями.
